# References

This file lists the sources behind the facts in this course: Epic's documentation and API
reference for Unreal Engine 5.8, the engine source code, and a few outside pages. Each chapter has
its own section, and the end of every chapter links to it. Use it to check a claim or to read
further.

Each source has two links. **original** is the live page. **archived** is a copy in a public
archive, in case the original moves or changes:

- Web pages link to the Internet Archive's [Wayback Machine](https://web.archive.org/). The link
  opens the snapshot closest to today.
- Engine source files link to [Software Heritage](https://archive.softwareheritage.org/), which
  archives public source repositories.

The archive links are built mechanically from the original URLs and were not checked one by one.
If a snapshot is missing, the archive offers to search for the nearest one. Epic's documentation
pages accept `?application_version=5.8` to pin the engine version. Source links point at a
public GitHub mirror of the engine (`OpenHUTB/engine`, branch `hutb`). Epic's own repository,
`EpicGames/UnrealEngine`, is visible only after you link your Epic Games account to GitHub. The
expected log lines in the chapters come from the course's own code and are not listed here.
